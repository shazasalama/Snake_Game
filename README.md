# Snake Game

## Description
This is a simple Snake Game developed using C language and graphics.h library.  
The player controls a snake that moves around the screen to eat food and grow longer.  
The game ends when the snake hits the wall or collides with itself.

---

## Features
- Classic Snake gameplay  
- Score tracking system  
- Snake grows when eating food  
- Collision detection (walls & self)  
- Simple grid-based movement  

---

## Technologies Used
- C Programming Language  
- graphics.h (BGI library)  

---

## How to Run
1. Open the project using Turbo C / Code::Blocks with graphics support  
2. Make sure BGI folder path is correct: C:\TC\BGI
